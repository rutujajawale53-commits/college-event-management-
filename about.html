About Campus Events

Campus Events is a static college event management website designed to provide students with information about college events, schedules, clubs and registration.

Our Objectives

  1. Provide event information in one place.
  2. Make event registration simple.
  3. Encourage student participation.
  4. Promote college clubs and activities.

Project Technologies

HTML is used for page structure and CSS is used for presentation, layout, colors, spacing and responsive design.
