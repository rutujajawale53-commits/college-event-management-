COLLEGE EVENT MANAGEMENT WEBSITE

How to run:
1. Extract the ZIP file.
2. Open the folder in VS Code.
3. Open index.html in a browser (or use Live Server).
4. Use the navigation bar to visit all pages.

Pages:
- index.html       Home
- events.html      Events
- schedule.html    Event schedule/table
- clubs.html       Student clubs
- gallery.html     Gallery
- registration.html Registration form
- about.html       About project
- contact.html     Contact/feedback

style.css contains the complete CSS styling and responsive design.

Note: This is a static HTML/CSS project. The registration and feedback forms are front-end only and do not store data.
